■サービス名
Auto_Shift

■サービス概要
シフト表をスキル設定によってバランスよく自動で作成し、シフトに関わる連絡を自動でしてくれるwebアプリです。

■ このサービスへの思い・作りたい理由
飲食店でバイトをしていた時に店長の仕事量が多く常に忙しそうにしていました。特に、シフト表の作成に苦労してたので、最終調整と確認だけで済むようなアプリがあれば、余裕を持って仕事ができると思い作りました。

■ ユーザー層について
シフト管理が必要な業務を行う飲食店、施設等のマネージャー、スタッフを想定しています。

■サービスの利用イメージ
ユーザー（マネージャー）がチームを作成し、全体的な働く日時や人数を設定しておく。ユーザー登録した人（スタッフ）とグループを作成する。マネージャーが設定した日時でスタッフに自動で連絡を行う。シフト希望の連絡、期日前にリマインドの連絡がスタッフに発信されます。シフト希望に沿って、簡単な操作で自動でシフト表が作成されます。完成したら、ユーザーに確認の連絡が一斉送信されます。マネージャーは必要なスキルをスタッフに設定でき、バランスよくシフト表が作成されます。

■ ユーザーの獲得について
サービスについてSNSで発信を行ったり、yutube等で使用方法の動画を作成

■ サービスの差別化ポイント・推しポイント
設定した日時にシフト希望の連絡やリマインドの連絡を自動で行ってくれたり、Airシフトにはないスキルの設定により、スタッフの可能な業務を考慮してシフト表が作成されるところがポイントです。
