サービス名
Auto_Shift

■サービス概要
シフト表を自動で作成し、シフトに関わる連絡を自動でしてくれるwebアプリです。

■ このサービスへの思い・作りたい理由
飲食店でバイトをしていた時に店長の仕事量が多く常に忙しそうにしていました。特に、シフト表の作成に苦労してたので、最終調整と確認だけで済むようなアプリがあれば、余裕を持って仕事ができるのではないかと思い作りました。

■ ユーザー層について
シフト管理が必要な業務を行う人々

■サービスの利用イメージ
管理者（店長）が全体的な働く日時や人数を設定し、ユーザー登録した人（バイト）が働けない曜日や日時をカレンダーで設定しておく。管理者が設定した日時でユーザーに自動で連絡を行う。休み希望日の連絡、期日前に催促の連絡がユーザーに発信される。管理者の簡単な操作でカレンダーに自動でシフト表が作成される。完成したら、ユーザーに確認の連絡が一斉送信される

■ ユーザーの獲得について
特に考えていません。

■ サービスの差別化ポイント・推しポイント
自動でシフト表を作成し、設定した日時に休み希望の連絡や催促の連絡を自動で行ってくれるところがポイントです。

■ 機能候補
  MVPリリース時、
  ・ユーザー登録機能
  ・管理者がシフト表をマニュアルでCRUDできる機能
  ・ユーザーの休み希望日を考慮して、自動でシフト表を作成する機能
  
  本リリース時
  ・ユーザーにメールで連絡する機能

   将来的な機能候補
  ・同様のスマホアプリ
  ・Line通知機能
  ・チャット機能

■ 機能の実装方針予定
　実装する機能
  ・gem 'sorcery'でユーザー登録機能
  ・JavaScriptでシフト表やカレンダー機能
  ・Bootstrapでボタン等のデザイン
  ・gem 'whenever'で設定した日時にメールを送信機能
  ・rubyで自動シフト割り当て機能
  
  ・ActionCableでチャット機能（将来）
  ・LINE Messaging APIでLine通知（将来）
  ・Flutterでスマホアプリを開発（将来）
