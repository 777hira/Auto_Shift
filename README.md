■サービス名
　Auto_Shift

■サービス概要
　シフト表を業務スキル設定によってバランスよく自動で作成し、シフトに関わる連絡を自動でしてくれるwebアプリです。

■ このサービスへの思い・作りたい理由
　飲食店でバイトをしていた時に店長の仕事量が多く常に忙しそうにしていました。特に、シフト表の作成に苦労してたので、最終調整と確認だけで済むようなアプリがあれば、余裕を持って仕事ができると思い作りました。

■ ユーザー層について
　シフト管理が必要な業務を行う飲食店や施設等のマネージャー、スタッフを想定しています。

■サービスの利用イメージ
　シフト管理を行う人がマネージャーとしてユーザー登録を行い、チームを作成し、連勤可能日数、業務スキルとその優先度を設定しておきます。シフト管理される人はスタッフとしてユーザー登録し、そのチームへの登録申請し、マネージャーが承認を行います。マネージャーが設定した日時でスタッフに自動で連絡を行います。休日希望の連絡、期日前にリマインドの連絡がスタッフに発信されます。
　シフト表を作成するにあたって、定休日、勤務時間、業務スキル毎に必要な人数、業務スキル、全体的な必要人数を設定し、あとは自動でスタッフの休日希望と連勤可能日数を考慮して、設定した優先度の高い業務スキルのを持ったスタッフからシフト表を埋めていき、埋まっていない日時を他のスタッフで埋めていくシフト表を生成します。業務スキル毎に必要な人数を満たしていない場合、その日時は赤く表示されます。マネージャーが確認、必要箇所の修正を行ったら、チームのユーザーに確認の連絡が一斉送信されます。マネージャーは業務スキルをスタッフに設定でき、バランスよくシフト表が作成されます。

■ ユーザーの獲得について
　サービスについてSNSで発信を行ったり、yutube等で使用方法の動画を作成し発信を行う

■ サービスの差別化ポイント・推しポイント
　設定した日時にシフト希望の連絡やリマインドの連絡を自動で行ってくれたり、Airシフトにはない業務スキルの設定により、スタッフの可能な業務を考慮してシフト表が作成されるところがポイントです。

■ 機能候補
  MVPリリース時
  ・ユーザー登録機能
  ・マネージャーがシフト表をマニュアルでCRUDできる機能
  ・スタッフのシフト希望に沿って、自動でシフト表を作成する機能
  ・スタッフにメールで連絡する機能
  ・業務スキル設定機能

  本リリース時
  ・Line通知機能
  ・役割にバイトを追加する機能（バイトはスタッフとは異なり、休日希望ではなく希望する出勤日時を選択でき、それを考慮してシフト表が生成される）

   将来的な機能候補
  ・同様のスマホアプリ
  ・チャット機能

■ 機能の実装方針予定
  実装する機能
  ・gem 'sorcery'でユーザー登録機能
  ・JavaScriptでシフト表やカレンダー機能
  ・Bootstrapでボタン等のデザイン
  ・gem 'whenever'で設定した日時にメールを送信機能
  ・rubyで自動シフト割り当て機能
  ・LINE Messaging APIでLine通知

  ・Flutterでスマホアプリを開発（将来）
